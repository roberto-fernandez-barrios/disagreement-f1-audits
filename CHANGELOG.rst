Release history
===============

1.2.0 — 26 October 2026
-----------------------

* Reader-first README, working access links, evidence map and English guides.
* Validated JSON audit adapter with explicit unknown labels and a runnable
  counterexample. The exact mathematical implementation remains unchanged.
* A single command interface for isolated verification, V4/full reproduction,
  portable PDF compilation and deterministic packaging.
* Complete dependency version lock and fresh-environment validation.
* Windows/Linux numerical CI and Ubuntu TeX Live build, with pinned actions
  and read-only repository permissions.
* About/topics/citation metadata aligned to the current GitHub release.
* 195 scientific files, including the V4 PDF, preserved byte for byte from
  1.1.0. No scientific result, author, protocol or manuscript claim changed.

The Zenodo DOI reserved for the V4 scientific snapshot is still pending
publication. Version 1.2.0 is cited through its GitHub tag/release and does not
claim that DOI. The manuscript remains prepared, not submitted or accepted.

1.1.0 — 25 October 2026
-----------------------

Manuscript V4: zero-loss control; six-point initial certification/tolerance
figure; descriptive cell dispersion; clearer exposition and primary-source
attribution; actual independent review and focused closure. Previous scientific
results preserved. Six-page PDF and reproducible artifact published on GitHub.

1.0.0 — 25 October 2026
-----------------------

Initial public artifact for manuscript V3.1: tolerance decisions, paired versus
marginal intervals and validation-selected comparators. Public Zenodo record
`10.5281/zenodo.23642981 <https://doi.org/10.5281/zenodo.23642981>`_. This is
an earlier version, not the V4 artifact.
