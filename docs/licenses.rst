Licenses and data attribution
=============================

Original analysis software and derived result tables use
`BSD-3-Clause <../LICENSE>`_. Frozen TDC predictions, labels, indices, validation
summaries and source exporters originate from TDC artifact **1.1.6**,
`10.5281/zenodo.21776862 <https://doi.org/10.5281/zenodo.21776862>`_, also released
under BSD-3-Clause. Its copyright and license are retained in ``LICENSE``.

The authors make ``paper/source/paper.tex`` and ``paper/paper.pdf`` available
under `Creative Commons Attribution 4.0 <https://creativecommons.org/licenses/by/4.0/>`_.
This is an author manuscript, not an accepted proceedings paper.

The ESANN class in ``paper/source/`` and the original template under
``paper/references/template/`` retain their original LaTeX Project Public License
and author notices; see their headers. They are not relicensed under BSD-3-Clause.

Original feature tables are not distributed. Rights over underlying datasets
are not conveyed by the derived artifact; consult the source TDC artifact for
attribution and acquisition. ``reproducibility/frozen_files.json`` identifies
the current paths and exact hashes of the reused files. The original
`third-party notice <../reproducibility/history/THIRD_PARTY_NOTICES.txt>`_ remains
unchanged as a historical record; the paths above describe the current layout.

The original ToN-IoT provider page (https://research.unsw.edu.au/projects/toniot-datasets)
requests citation of eight family publications. The six-page paper cites the
publication matching the network component actually used; the provider page
lists the broader family references and use conditions. This artifact redistributes
only the frozen derived TDC predictions, not the raw ToN-IoT dataset.
