This is an implementation plan, not a preregistration. The user supplied

1. Primary new decision: epsilon=1/100 absolute positive-class F1. For the
exact joint completion interval [L,U], Rq=max(0,-L), Rc=max(0,U). Choose q

<=epsilon. Epsilon zero is a weak-winner decision, different from the old
three-way strict-winner/exact-tie goal. Use integer rational comparisons for
boundary decisions. F1(0/0)=0, allow P=0,n in the query experiment.

2. Same 3200 deduplicated pairs, 36 cells, three original policies and seeds
0..31. Preserve their permutation generation and exact-sign stopping costs.
Compute tolerance stops using only acquired counts, with no labels used to
choose an order. Offline prefix computation/binary search may accelerate
replay: it must return the first certifiable prefix; the preceding prefix
must fail and all labels used in a certificate must be in that prefix.
Full labels are used only in retrospective verification. Report all-pair
common cohort, initially exact-undecided cohort and initially epsilon-
undecided cohort separately; report D, extra agreement queries, total.
Aggregate orders then pairs within cells then equal cells; retain pair means.

3. Compare joint difference bounds with subtraction of marginal F1 bounds

Report widths and strict/tie, weak-winner and epsilon decisions. This is a
dependency-preservation comparison, not a competitor to joint TDC/Polo.
